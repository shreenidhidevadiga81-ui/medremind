# MedRemind

A medicine reminder and care management app for old age homes.

Built with React, FastAPI (Python), PostgreSQL, and machine learning.

## Roles
- Admin: manages nurses, residents, and complaints
- Nurse: records doses, vitals, and attendance
- Family: views their own relative's status (view only)

## Status
Work in progress.

> Note: This project uses only sample (fake) data. No real health information is stored.
